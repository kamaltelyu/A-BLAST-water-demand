# Notebooks

This folder contains the original experimental notebooks used to reproduce the A-BLAST water demand forecasting experiments.

## Included notebooks

- `CHENNAI.ipynb`  
  Experiment notebook for the Chennai Water Management dataset.

- `MELBOURNE.ipynb`  
  Experiment notebook for the Melbourne Water Supply dataset.

These notebooks include the preprocessing workflow, model execution, evaluation, and result generation steps used in the associated MethodsX manuscript.

## Notes

The raw datasets are not bundled in this repository. Users should download the datasets from their original public sources and place them in the `data/raw/` directory before running the notebooks.
