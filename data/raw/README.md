# Raw data directory

Place the raw datasets here before rerunning the full experiments.

Suggested structure:

```text
data/raw/
├── chennai/
│   ├── chennai_reservoir_levels.csv
│   └── chennai_reservoir_rainfall.csv
└── melbourne/
    └── MWC_Daily_BulkWaterSupply_CompleteRecord_*.csv
```

Raw datasets are not included in this repository unless their licenses explicitly allow redistribution.
